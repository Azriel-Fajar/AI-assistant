# Caption Playbook — Rielcode

Knowledge base for the `/caption` skill. Distilled from 2026 caption research + Rielcode context. Apply these; don't dump them in output.

---

## 1. Core structure — HVC

Every caption = **Hook → Value → CTA**.

- **Hook** = first line. The ONLY job: earn the tap / stop the scroll. Front-load it.
- **Value** = deliver the promise. Specific, not generic. One idea.
- **CTA** = one clear next step (chat, save, DM, link).

Meta study: structured caption + clear CTA = ~23% more engagement.

## 2. The 125-character rule

- IG/FB truncate at ~125 chars ("...more"). The hook must land in the **first 80-125 chars**.
- If line 1 could belong to any competitor, it's too generic. Rewrite.
- Treat line 1 like an email subject line.

## 3. Hook types (pick one per caption)

| Type | Pattern | Example seed |
|------|---------|-------------|
| Curiosity gap | tease, don't explain | "Website bisnis mahal? Nggak juga." |
| Contrarian | break a common belief | "Kebanyakan UMKM rugi gara-gara ini." |
| Story | open mid-action | "Temen gue baru bikin website bisnisnya..." |
| Social proof | lead with a result | "Client ini naik order 2x setelah punya website." |
| Problem (PAS) | name the pain first | "Jualan masih cuma lewat DM?" |

Avoid tired "3 tips" / "how to" openers — people scroll past formulaic hooks.

## 4. Frameworks (use as needed)

- **AIDA** — Attention, Interest, Desire, Action. Best for short social/CTA copy, reels, TikTok.
- **PAS** — Problem, Agitate, Solution. Best when leading with a pain point. Empathy first, then solution.
- **FOMO/urgency** — "slot terbatas", "promo bulan ini" — use sparingly, only when真 true. Fake urgency = cringe.

## 5. 2026 algorithm shifts

- **Saves + shares > likes.** Write captions worth saving or sending to a friend.
- **Keywords > hashtags.** Weave natural search terms ("jasa pembuatan website", "website UMKM") into the text. IG now indexes caption text for search.
- Hashtags: 1-3 max, relevant. NOT a wall of 20. Especially on friend reposts — hashtag spam = looks like an ad.

## 6. Platform specifics

| Platform | Length | Notes |
|----------|--------|-------|
| Instagram feed | 138-150 chars ideal, hook in first 125 | keywords for search, 1-3 hashtags |
| Instagram Reels/Story | very short, hook-only | caption = secondary hook to the video |
| TikTok | 50-150 chars, punchy | let video talk; caption complements opening |
| WhatsApp Status | short, personal, no hashtags | feels like a friend's update, not an ad |
| Facebook | medium, can be slightly longer | community/story tone works |

## 7. Two voices — CRITICAL

### Brand voice (@rielcode posts)
- Professional, direct, confident. Per project communication-style: no emojis spam, no em dashes, no overly formal language, one idea per sentence.
- Sells the outcome: fast, affordable, professional websites.
- Light. Not corporate-stiff, not hype-bro.

### Friend / referral voice (friends reposting)
- Casual, low-key, lowercase ok. Sounds like a real person, NOT an ad.
- A genuine vouch: "temen gue bikin website di sini, hasilnya bagus."
- NO hype words ("untung gue kenal!", "buruan!"), NO fake urgency, minimal/no hashtags.
- If it reads like marketing, it failed. Throwaway-easy is the goal.
- This is the voice that fixes the "too cringe" problem.
