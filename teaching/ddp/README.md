Course: Dasar-Dasar Pemrograman (DDP)
Co-assistant(s): Cynthia Elena Gunadi

## Folders
- `slides/` -- one markdown file per meeting (`NN-topic.md`). File content = the slide content for that meeting.

## Workflow
1. Write meeting content in `slides/NN-topic.md`.
2. Run `/slides` on that file to render the deck.
