# Rielcode Referral Program

## Program Rules

- **Commission:** 10% of project value, paid after client payment clears
- **No referral limit** per person
- **No expiry** — program runs indefinitely
- Client must enter the referral code at checkout on rielcode.com
- Commission paid via bank transfer within 3 days of project payment
