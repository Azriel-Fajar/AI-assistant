1. Data Collection

1.1 Data Source

The data used in this project is the number of higher education institutions (universities) per regency/city (kabupaten/kota) in Indonesia in 2023, published by the Indonesian government open data portal:

Source: data.go.id – “Jumlah Perguruan Tinggi menurut Akreditasi dan Wilayah, Tahun 2023”
https://data.go.id/dataset/dataset/jumlah-perguruan-tinggi-menurut-akreditasi-2024

The quantitative variable analyzed is Total semua: the total number of higher education institutions (both under Kemendikbudristek and non-Kemendikbudristek) in each regency/city. The observation unit is one regency/city. The dataset covers the provinces of Banten, D.I. Yogyakarta, D.K.I. Jakarta, Jawa Barat, Jawa Tengah, and Jawa Timur, giving n = 117 observations, which satisfies the minimum requirement of 100 observations.

2. Frequency Distribution Table

2.1 Constructing the Table (Sturges’ Method)

Step 1. Highest value = 85 (Kota Surabaya), lowest value = 1. Range = 85 − 1 = 84.

Step 2. Number of class intervals using Sturges’ formula:

k = 1 + 3.322 log n = 1 + 3.322 log 117 = 1 + 3.322 (2.0682) = 7.8705 ≈ 8 classes (rounded up)

Step 3. Width of class interval:

c = (highest − lowest) / k = (85 − 1) / 8 = 10.5 ≈ 11 (rounded up so all data fits)

Step 4. The lowest class limit is the lowest value, 1, so the first class is 1 – 11 with class limits 0.5 – 11.5. With 8 classes of width 11, the last class is 78 – 88 (77.5 – 88.5), which covers the maximum value 85. All 117 observations are accommodated.

4. Descriptive Analysis

4.1 Minimum, Maximum, and Range

  • Minimum = 1 university (Kab. Kulon Progo, Kab. Pangandaran, Kab. Madiun, Kota Probolinggo).
  • Maximum = 85 universities (Kota Surabaya), followed by Kota Bandung, Kota Jakarta Selatan, and Kota Jakarta Timur with 78 each.
  • Range = 85 − 1 = 84, a very wide spread relative to typical values.

4.2 Distribution Shape

The distribution is strongly right-skewed (positively skewed). The histogram shows the tallest bar at the first class (1 – 11) with 69 regencies/cities (58.97% of all observations), frequencies falling off rapidly, and a long thin tail stretching to the right. Two classes in the tail (56 – 66 and 67 – 77) are even empty before a small cluster of 4 extreme values appears in the last class (78 – 88).

The ogive confirms this: it rises very steeply at the beginning and flattens quickly — 99 of 117 regions (84.62%) already have 22 or fewer universities, and 107 regions (91.45%) have 33 or fewer.

4.3 Key Insights

  1. Higher education is highly concentrated. The majority of regencies/cities (58.97%) host at most 11 institutions, while a handful of large cities host dozens.
  2. The extreme values are all major metropolitan cities: Surabaya (85), Bandung (78), Jakarta Selatan (78), and Jakarta Timur (78). These are outliers far from the rest of the data, creating the isolated last class in the histogram.
  3. Kabupaten vs Kota gap. Nearly all high-frequency regions in the upper classes are cities (kota), while regencies (kabupaten) dominate the lowest class, showing that university access is centered in urban areas.
  4. Consequence of skewness. Because of the strong right skew, the mean would be pulled well above the median; the median or mode is a more representative measure of a “typical” regency/city than the mean for this data.

4.4 Conclusion

Using Sturges’ formula, the 117 observations were grouped into 8 classes of width 11. The frequency distribution, histogram, frequency polygon, and ogive all show a strongly right-skewed distribution: most regencies/cities in Java and Banten have very few higher education institutions, while a small number of metropolitan cities concentrate most of them. This reflects the real-world centralization of higher education in Indonesia’s big cities.
