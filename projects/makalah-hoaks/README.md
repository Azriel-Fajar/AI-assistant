## Format rules (dari template dosen)
- BAB I Pendahuluan: Latar Belakang (buka dengan kasus nyata + footnote berita), Rumusan Masalah (3 pertanyaan), Tujuan (3 poin paralel)
- BAB II Pembahasan: 3 subbab sesuai rumusan masalah, kutipan langsung menjorok, footnote nomor urut
- BAB III Penutup: Kesimpulan (3 poin, jawab tiap rumusan), Saran (2 poin)
- Daftar Pustaka: Nama, (tahun), judul italic, kota: penerbit; sumber online dengan URL + tanggal akses
- Gaya bahasa: formal "saya"-less, paragraf sedang, lihat memory reference_azriel_academic_writing_style
