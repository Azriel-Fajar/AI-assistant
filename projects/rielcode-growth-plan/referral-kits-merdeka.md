## What changed vs the base kits

- Captions are framed as a 17 Agustus promo, not an evergreen vouch.
- Hard deadline: **31 Agustus 2026** (the base kits said "sampai 30 Juni", long expired).
- Price is stated ("mulai 1 juta"). Filters freebie-seekers before they message.
- "Demo tampilan gratis" only. Never "lihat hasilnya dulu" or anything readable as pay-on-success.
- Video is the Merdeka ad, not the launch ad.

## How to use (Azriel side)

1. Copy ONE friend's block below.
2. Send it to that friend on WhatsApp, with their video file attached.
3. Lead checks out with the code, 10% comes off, you see the code on the order, you reward that friend.

The code IS the tracking. No manual "saya dari [name]" tally.

## Reward (double-sided, unchanged)

- Client uses the friend's code, client gets **10% off** any package.
- Friend earns **10% of the closed project value**, paid after the deposit clears.
- No code on the order = no reward.

## Video assets

Merdeka per-friend renders: `my-video/out/merdeka/<CODE>/{reel-9x16,feed-4x5}.mp4`

VO never speaks a code. It says "pakai kodenya" and the badge shows theirs, so the same audio works for every friend. See the code-agnostic note in `projects/merdeka-campaign/README.md`.
