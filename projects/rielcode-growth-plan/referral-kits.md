# Referral Kits — Per Friend (ready to forward)

_Created: 2026-06-22. Replaces the seller-voice captions in `referral-links.md` (those read like ads, friends won't post them)._

## How to use (Azriel side)

1. Copy ONE friend's block below.
2. Paste into WhatsApp, send to that friend.
3. They have everything: video, caption, their code, where to post.
4. Lead checks out with the code -> 10% off auto-applied -> you see the code on the order -> reward that friend.

No manual "saya dari [name]" tally. The code IS the tracking.

## Reward (double-sided)

- New client uses the friend's code at checkout -> **client gets 10% off** any package. Referral codes are ongoing, no expiry.
- Friend earns **10% of the closed project value**, paid after deposit clears.
- Tracking = the code on the order. No code = no reward.
- 10% of a 4jt project = 400rb. Scales with project size.

## Video assets

Per-friend videos already rendered: `my-video/out/referrals/<CODE>/{reel,feed,story,wa}.mp4`
- Reel/Story/WA = 9x16 (IG Story, WA Status, Reels, TikTok)
- Feed = 4x5 (IG/FB feed)

VO speaks the discount, badge shows their code. Friend just posts the file.

## The friend-voice caption (why it works)

Friends posting a polished ad = looks fake, nobody taps. The caption below is a genuine vouch: lowercase ok, no hype, no fake urgency, minimal hashtags. Sounds like a real person telling a friend. That is what converts on a repost.

Each friend gets: WA Status line + IG/Story caption + their code + chat link.
