Rielcode video VO is supplied by Azriel as mp3 files, not generated by Claude. No TTS API key exists in env or `.env`, and there is no TTS gen script in the repo (prior `vo-*.mp3` made via an external tool, likely ElevenLabs UI).

**Why:** Cannot auto-generate VO. Founder/AI VO is produced outside the toolchain and dropped into `my-video/public/`.

**How to apply:**
- Tell Azriel the exact filename + path to save (e.g. `my-video/public/vo-launch.mp3`, or per-scene `vo-launch-hook.mp3`, `-site`, `-code`, `-cta`).
- He may split VO per scene. Wire each clip into its scene component with `<Audio src={staticFile("...")} />` (Series resets frame per scene, so scene-local Audio auto-starts at the cut).
- For static assets, sequence clips with `<Sequence from={N}>` wrapping `<Audio>`.
- Check each clip duration (via `@remotion/media-parser`) fits its scene/composition length before rendering.
- Default static VO = hook clip then code clip in sequence.
See [[reference_remotion_video_project]].
