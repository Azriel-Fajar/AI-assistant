In `leads/leads.md` there are two separate tables: the **Leads** table (top) and the **Active Potential Customers** table (bottom). Keep them distinct and reference by Azriel's wording.

**Why:** Azriel tracks raw outreach leads separately from qualified/proposal-stage clients. Mixing them up pulls the wrong record.

**How to apply:**
- If Azriel says "leads" / "lead" / a lead ID (e.g. 019) -> pull from the Leads table.
- If Azriel says "customer", "client", "potential client", or anything in between -> pull from the Active Potential Customers table (Cust 1, 2, ...).
- A single contact can appear in both tables (e.g. lead ID 019 = Cust 6); the table chosen depends on the word Azriel used.
