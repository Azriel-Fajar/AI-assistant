Client-facing testimonial submission page for Rielcode.

**Why:** Clients need a place to submit testimonials; send them a link after project delivery.

**How to apply:** When building or discussing this feature, scope it as a subdomain page (e.g., testimonials.rielcode.com) with a form. Keep it simple — name, role/company, message, optional photo.

## Key Notes

- Subdomain: likely `testimonials.rielcode.com` or `review.rielcode.com`
- Form fields to consider: name, company/role, testimonial text, star rating, optional photo upload
- Submissions should save somewhere (DB or Google Sheets) and ideally notify Azriel
- Display approved testimonials publicly or pull them into portfolio/main site
- Send link to clients after project delivery as part of handoff flow
