Invoice system must support both IDR and USD.

**Why:** Azriel serves both local Indonesian clients (IDR) and international clients like Parallaxnet Canada (USD).

**How to apply:** When building or suggesting invoice features for Rielcode, always include multi-currency support (IDR + USD) as a requirement.
