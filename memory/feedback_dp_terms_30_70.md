Rielcode payment terms: DP 30% upfront to start, 70% on completion after customer checks the result. Hosting and domain are bought only AFTER the DP is received, never before.

**Why:** 20% DP on Starter (1jt) = 200rb, but hosting + domain costs 250-400rb. If the client bails after Rielcode buys hosting, Rielcode loses money (happened with Cust 2, lost ~50rb). 30% covers the outlay together with the buy-after-DP rule.

**How to apply:** All NEW quotes/WA/proposal/follow-up copy use DP 30% start / 70% on delivery. Existing in-progress clients quoted at 20/80 keep 20/80. Never default to 50/50. Related: [[feedback_wa_funds_objection_tone]], [[feedback_wa_client_tone]].
