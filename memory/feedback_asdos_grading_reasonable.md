When grading Azriel's asdos students (Matdis, hukum ekuivalensi etc.), weigh each error by severity with judgment. Do not apply mechanical fixed deductions like "-2 per wrong line". Always give a reason for every score and every deduction.

**Why:** Azriel rejected a rigid -2/line slip rule as too formulaic. He wants answers judged on correct logic and result, not exact match with the answer key.

**How to apply:** Small notation slips that the next line fixes = small deduction. Wrong law name = small. Wrong core step (e.g. De Morgan operator flipped) = bigger. Missing law name = -1 per step (Azriel's rule, 2026-10-17). Merged laws with only one named (e.g. Komutatif without Asosiatif, Negasi Ganda folded into De Morgan) = no deduction. Final answer must have no arrows. Reasons must be dense and clear: one short line per deduction ("-2 hukum Implikasi tidak ditulis"), no long explanations. See [[user-academic-credentials]].
