Rielcode pricing lives at `references/rielcode-pricing.md` (source: Laravel app /services). Use it for any quote/proposal/follow-up.

Base packages (IDR / USD):
- Student 500k/$29 — 1 page, basic SEO, NO free hosting/domain
- Starter 1jt/$58 — 1-2 pages, basic SEO, free domain+hosting 1yr, SSL
- Pro 2jt/$116 (Most Popular) — up to 5 pages, advanced SEO, Basic CMS, Google Analytics+Search Console, domain+hosting 1yr, 1mo support
- Premium 5jt/$290 — up to 10 pages, Standard CMS, AI chatbot, e-commerce, perf optimization, 2mo support
- Custom — from 500k, quote per scope

Key add-ons: CMS from 600k, AI Chatbot 1jt, Analytics+Search Console 300k, Advanced SEO 200k, Blog/News 400k, Login/Member 500k, E-commerce from 1jt, Extra page 85k, Maintenance 300k/mo, Priority Delivery (50% faster) 300k.

Note: Pro already bundles advanced SEO + CMS + analytics, so for multi-page SEO sites Pro is usually cheaper than Starter+add-ons.
