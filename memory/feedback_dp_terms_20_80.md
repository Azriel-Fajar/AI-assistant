Rielcode payment terms: DP 20% upfront to start, 80% on completion after customer checks the result.

**Why:** Azriel corrected a 50/50 DP draft. 20/80 is the standard split, lower upfront barrier to close.

**How to apply:** When quoting payment terms in any WA/proposal/follow-up, use DP 20% start / 80% on delivery. Never default to 50/50. Related: [[feedback_wa_funds_objection_tone]], [[feedback_wa_client_tone]].
