Viral ad system at `meta/creative/`, adapted from "How to Make VIRAL Ads That Make You Millions" (transcript in [[meta/viral-ads.md]]).

Structure:
- `README.md` — 8-step SOP: research, bullseye, hook, pattern match, pattern interrupt (repeated), 10-12 multi-hooks per concept, sell against alternatives, render/launch/rotate.
- `swipe/INDEX.md` + `thumbnails/` + `titles/` — attention database. Azriel screenshots every thumbnail/title that grabs him; drops PNG in folder OR pastes in chat; Claude logs file + why-it-hooked + pattern type (match vs interrupt) + reuse idea. On "log swipes", read the folders and fill INDEX.
- `research/bullseye.md` — verbatim customer pain quotes boiled to ONE bullseye: TRUST (IG-only looks small, site makes you believable). Alternatives to sell against: IG-only, cheap Rp50k template, nephew, abandoned Wix.
- `hooks.md` — 12-hook bank for v3 WhatsApp, one TRUST concept. Rotate next hook when freq >~1.7 / CPM rises. Fixes v3 fatigue.

Renders from `my-video/RielcodeAd/` ([[reference_remotion_video_project]]). Render rules locked per [[feedback_remotion_fast_paced_3s_frame]] and [[feedback_ad_script_customer_pov]]. Ties to [[project_meta_ads_v3_whatsapp]] and [[feedback_close_gap_not_leadgen]] (creative fixes close, not new channels).
