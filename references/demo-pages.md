## Rules

- Never invent a slug. If no demo matches the niche, send the closest one and say it is a different industry but the same structure, or send the hub `rielcode.com/demos/`.
- Always state the design is a rough draft and fully customizable.
- Phrasing skeleton: "Ini website demo X yang ada di website kami kak:" + URL + list of pages + "modelnya cocok sama yang kakak bayangin?"
- Re-verify this list against the demos folder after adding or removing a demo.
