Apa itu Inferensi

Setelah data dianalisis, dilakukan inferensi (pengambilan keputusan tentang populasi berdasarkan sampel). Inferensi dibagi menjadi dua cara: selang/interval konfidensi dan uji hipotesis.

Jenis DataPengujianStatistik
Kuantitatif (angka)tes satu sampelparametrik
Kualitatif nominaltes binomial, chi-kuadratnon-parametrik
Kualitatif ordinalrun testnon-parametrik

Lambang

μ = rata-rata populasi (sebenarnya, tidak diketahui)  •  x = rata-rata sampel
σ² = variansi populasi  •  s² = variansi sampel  •  α = batas kepercayaan (1 − α = tingkat konfidensi)

Interval Konfidensi (1 − α) untuk μ

Jika σ² diketahui:
x − zα/2 · (σ/√n)  ≤  μ  ≤  x + zα/2 · (σ/√n)

Jika σ² tidak diketahui (pakai s):
x − zα/2 · (s/√n)  ≤  μ  ≤  x + zα/2 · (s/√n)
Untuk n ≥ 30 (sampel besar), distribusi z tetap berlaku walau σ tidak diketahui.
Inferensi Statistika - Interval KonfidensiHalaman 1

Latihan: Bola Lampu

Suatu pabrik listrik yang membuat bola lampu ingin mengetahui rata-rata panjang umur bola lampu yang dibuat. Diambil 36 bola lampu secara random, diperoleh rata-rata panjang umur 780 jam dengan standar deviasi 40 jam. Hitung interval konfidensi 96% untuk rata-rata panjang umur keseluruhan bola lampu.

nxsKonfidensi
36780 jam40 jam96%

Langkah 1: Cari α

Konfidensi 96% → 1 − α = 0.96 → α = 0.04 → α/2 = 0.02

Langkah 2: Cari z0.02

Cari z dengan P(Z < z0.02) = 1 − 0.02 = 0.98
Dicari pada tabel kurva normal → z0.02 = 2.05

Langkah 3: Hitung Margin

zα/2 · (s/√n) = 2.05 · (40/√36)
= 2.05 · (40/6) = 2.05 · 6.667 = 13.67

Langkah 4: Susun Interval

780 − 13.67 ≤ μ ≤ 780 + 13.67
766.33 ≤ μ ≤ 793.67
Kesimpulan: Dengan tingkat kepercayaan 96%, rata-rata panjang umur keseluruhan bola lampu yang dibuat berada di antara interval 766.33 jam dan 793.67 jam.

Uji Hipotesis

Pengujian Rata-rata Satu Populasi (n ≥ 30)

Pengertian

Hipotesis adalah pernyataan mengenai parameter populasi. Pengujian dilakukan untuk menerima atau menolak pernyataan tersebut berdasarkan data sampel.

Langkah-langkah

1. Merumuskan hipotesis (tiga kemungkinan bentuk):
a. H0 : μ = μ0  lawan  H1 : μ ≠ μ0  (dua arah)
b. H0 : μ ≤ μ0  lawan  H1 : μ > μ0  (satu arah kanan)
c. H0 : μ ≥ μ0  lawan  H1 : μ < μ0  (satu arah kiri)

2. Menentukan tingkat signifikansi (tingkat kesalahan) α

3. Menentukan statistik penguji:
Z = (x − μ0) / (σ/√n) jika σ diketahui
Z = (x − μ0) / (s/√n) jika σ tidak diketahui

4. Menentukan daerah kritis (daerah penolakan H0):
a. Dua arah: H0 ditolak jika Z < −zα/2 atau Z > zα/2
b. Satu arah kanan: H0 ditolak jika Z > zα
c. Satu arah kiri: H0 ditolak jika Z < −zα

5. Mengambil kesimpulan
Inferensi Statistika - Uji HipotesisHalaman 3

Latihan: Bola Lampu (Uji Hipotesis)

Dengan data yang sama (36 bola lampu random, rata-rata umur 780 jam, standar deviasi 40 jam): apakah dari data yang diperoleh bisa dikatakan bahwa rata-rata umur bola lampu adalah 800 jam, dengan tingkat kesalahan 2%?

nxsμ0α
36780 jam40 jam800 jam0.02

1. Merumuskan Hipotesis

H0 : μ = 800
H1 : μ ≠ 800  (uji dua arah)

2. Tingkat Signifikansi

α = 0.02

3. Statistik Penguji (σ tidak diketahui)

Z = (x − μ0) / (s/√n)
Z = (780 − 800) / (40/√36) = −20 / (40/6) = −20 / 6.667 = −3.00

4. Daerah Kritis

H0 ditolak jika Z < −z0.01 atau Z > z0.01
Untuk mencari z0.01: P(Z < z0.01) = 1 − 0.01 = 0.99
Dicari pada tabel kurva normal, didapat z0.01 = 2.33
Sehingga: H0 ditolak jika Z < −2.33 atau Z > 2.33

5. Kesimpulan

Karena Z = −3.00 → Z < −2.33, maka memenuhi daerah kritik, sehingga H0 ditolak. Jadi hipotesis bahwa rata-rata panjang umur keseluruhan bola lampu adalah 800 jam ditolak. Dengan tingkat kesalahan 2%, rata-rata umur bola lampu berbeda secara signifikan dari 800 jam.
