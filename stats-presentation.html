Step 1 - Range

Highest value = 176  •  Lowest value = 119  •  n = 40
Range = 176 − 119 = 57 pounds

Step 2 - Number of Classes (Sturges)

k = 1 + 3.322 log n
k = 1 + 3.322 × log 40 = 1 + 3.322 × 1.602 = 1 + 5.32 = 6.32 → round up to 7 classes

Step 3 - Class Width

c = (highest − lowest) / k
c = 57 / 7 = 8.14 → round up to 9
Lowest class limit = lowest value = 119. Width 9 guarantees all data fits (including 176).

Mean

x = Σ(f · x) / Σf
x = 5874 / 40 = 146.85

Median

Md = L + ((n/2 − F) / f) · c
20th value falls in class 146–154. L = 145.5, F = 19, f = 11, c = 9.
Md = 145.5 + ((20 − 19) / 11) · 9 = 145.5 + 0.82 = 146.32

Mode

Mo = L + (a / (a + b)) · c
Highest frequency is class 146–154 (f = 11). L = 145.5, a = 11 − 10 = 1, b = 11 − 5 = 6, c = 9.
Mo = 145.5 + (1 / 7) · 9 = 145.5 + 1.29 = 146.79

Quartile (Q1)

Position of Q1 is the (n / 4)-th value. Q₁ = L + ((n/4 − F) / f) · c

Q1 → pos = 40 / 4 = 10 → class 137–145 (L = 136.5, F = 9, f = 10, c = 9)
Q1 = 136.5 + ((10 − 9) / 10) · 9 = 136.5 + 0.9 = 137.40
Lower quarter of adults weigh below 137.4 lb.

Decile & Percentile

Position of Dx is (n·x/10), of Px is (n·x/100). (The brief lists "15th decile" but only D1–D9 exist; D5 is shown, which equals the median.)

Dₓ = L + ((n·x/10 − F) / f) · c
D5 → pos = 40×5/10 = 20 → class 146–154
D5 = 145.5 + ((20 − 19) / 11) · 9 = 146.32

Pₓ = L + ((n·x/100 − F) / f) · c
P10 → pos = 40×10/100 = 4 → class 128–136 (L = 127.5, F = 3, f = 6)
P10 = 127.5 + ((4 − 3) / 6) · 9 = 129.00
