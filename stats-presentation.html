Step 1 - Range

Highest value = 176  •  Lowest value = 119  •  n = 40
Range = 176 − 119 = 57 pounds

Step 2 - Number of Classes (Sturges)

k = 1 + 3.322 log n
k = 1 + 3.322 × log 40 = 1 + 3.322 × 1.602 = 1 + 5.32 = 6.32 → round up to 7 classes

Step 3 - Class Width

c = (highest − lowest) / k
c = 57 / 7 = 8.14 → round up to 9
Lowest class limit = lowest value = 119. Width 9 guarantees all data fits (including 176).

Ogive (Cumulative Frequency Curve)

Plots cumulative frequency against the upper class limit of each class. Shows how many adults weigh below a given value.

Reading the Ogive

• 30 of 40 adults weigh under 154.5 lb
• Median weight (20th value) falls in the 146–154 class
• Curve always rises, ending at n = 40

Summary

1. Find range → 2. Sturges for class count (7) → 3. Width (9) → 4. Tally into table → 5. Draw histogram, polygon, ogive.
The distribution peaks at the 146–154 class, most adults cluster around 150 lb.
